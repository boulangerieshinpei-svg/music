# ボカロ作曲スケッチ

ボカロ曲の**たたき台**を作るためのブラウザアプリ。
作詞・Aメロ／Bメロ／サビの構成・コード進行を**小節単位**で組み立てて、
気に入らない小節だけ AI に書き換えさせる、という作り方ができます。

ビルド不要。`index.html` を開けば動きます。

## できること

| | |
|---|---|
| **セクション構成** | Intro / Aメロ / Bメロ / サビ / Cメロ / Outro を追加・並べ替え・複製・削除 |
| **小節ごとの編集** | 1小節 = コード1つ + 歌詞1行。小節数は自由に増減 |
| **モーラ数の自動カウント** | 拗音は1モーラ、「っ」「ん」「ー」も1モーラで計算。目標モーラとのズレを色で表示 |
| **コードパレット** | 現在のキーのダイアトニック、借用・セカンダリドミナントなどのスパイス、定番進行14種 |
| **メロディ** | 小節の下のグリッドをタップして音を置く。コードの構成音の行が光るので、そこを叩けば必ずハマる |
| **たたき生成（AIキー不要）** | 雰囲気とセクションの役割から、コード進行・歌詞・メロディのたたきをオフラインで生成 |
| **AIで書き換え** | 小節単位／選択した小節／セクション全体を Claude が書き換え（歌詞・コード・メロディ）。指示文で方向づけできる |
| **移調** | キーを変えると全コードが追従。半音上げ／下げボタンつき |
| **再生** | Web Audio でコードとメロディを一緒に鳴らして確認（パッド／アルペジオ／刻み、クリック付き。パートごとにオフにできる） |
| **スマホ対応** | 1小節を画面幅いっぱいに表示。ホーム画面に追加してアプリのように使える |
| **保存・書き出し** | 自動でブラウザに保存。JSONで書き出し／読み込み、歌詞・コード譜をクリップボードへ |

## 使い方

```bash
# どれかの方法でローカルサーバーを立てて開く
python3 -m http.server 8000
# → http://localhost:8000
```

ES モジュールを使っているので、`file://` で直接開くとブラウザにブロックされます。
かならずローカルサーバー経由で開いてください。

### 作り方の流れ

1. 上部でキー・BPM・雰囲気・テーマを決める
2. セクションごとに `🎲 コード` でコード進行のたたきを出す（気に入らなければ何度でも）
3. `🎹` でパレットを開き、小節を選んでコードを差し替える
4. `🎲 歌詞` でモーラ数に合う歌詞のたたきを入れる
5. 直したい小節にチェックを入れて、下の指示欄に「もっと切なく」などと書いて `✨ AI歌詞`
6. `🎲 メロディ` でメロディのたたきを出し、小節下のグリッドをタップして直す
7. `▶` で鳴らして確認 → 3〜6を繰り返す

小節右上の `✨` は、その1小節だけを AI に書き換えさせるボタンです。

### メロディの付け方

小節の下のグリッドが、その小節のメロディです。

- **縦** … キーのスケール音（上ほど高い）。**そのコードの構成音の行に色が付く**ので、色の付いた行に置けば外れません
- **横** … 小節の分割（4分／8分／16分。セクションごとに切り替え）
- **タップ** で音を置く／消す。置いた瞬間に音が鳴ります
- **右へドラッグ** で音が伸びます
- PC では**なぞって連続入力**できます

`♪6音` は、その小節に置いた音の数。歌詞のモーラ数と揃うと緑になります
（1音1文字で歌えるということ）。`🎲 メロディ` は、歌詞が入っていればそのモーラ数に音数を合わせて作ります。

音程は「キーのスケール上の段数」で保存しているので、**移調してもメロディがキーに追従**します。

### モーラ数の見方

`8 / 7 モーラ` は「今8音、目標7音」の意味。
- 緑 … 目標±1（そのまま乗る）
- 黄 … ±3以内（詰めれば乗る）
- 赤 … それ以上（作り直したほうが早い）

漢字が含まれると読みが確定しないため `⚠` が出て、モーラ数は目安になります。
AI が書いた歌詞は読み（yomi）も一緒に返るので `♪` が付き、正確に数えられます。

## AI機能の設定

⚙ ボタンから Anthropic の API キーを入れると、AI機能が使えるようになります。
キーが無い場合でも `🎲 たたき` 系のボタンはすべて動きます。

**キーの扱いについて:** APIキーはブラウザの `localStorage` に保存され、
リクエストはブラウザから直接 `api.anthropic.com` に送られます
（`anthropic-dangerous-direct-browser-access` を有効にしています）。
**自分のPCで自分のキーを使う前提**のツールです。
共有PCや、誰でも開ける場所にホスティングして使わないでください。

モデルは Opus 5 / Sonnet 5 / Haiku 4.5 から選べます。迷ったら Opus 5。

## ファイル構成

```
index.html        画面
assets/styles.css スタイル
src/
  theory.js       キー・コード・移調・ダイアトニック・定番進行
  mora.js         日本語のモーラ数カウント、韻の判定
  state.js        プロジェクトのデータモデルと保存
  generator.js    オフラインのたたき生成（歌詞・コード）
  melody.js       メロディのデータ操作と、たたきメロディの生成
  audio.js        Web Audio によるコード・メロディ再生
  ai.js           Claude API 連携
  app.js          画面の組み立てとイベント配線
```

## スマホで使う（デプロイ）

`.github/workflows/deploy.yml` を入れてあるので、GitHub Pages に自動デプロイできます。

初回だけ手動の設定が必要です:

1. GitHub の **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. デフォルトブランチに push する（以降は push のたびに自動で反映されます）

公開された URL をスマホで開き、ブラウザの「ホーム画面に追加」をすると、
アドレスバーなしのアプリとして起動します（`manifest.webmanifest` を同梱）。

### Firebase ではなく GitHub Pages にした理由

このアプリはサーバー処理もデータベースもログインも使わない、完全な静的サイトです。
Firebase を使っても Hosting しか出番がなく、Firestore / Auth / Functions は丸ごと遊びます。
リポジトリが既に GitHub にあるので、Pages なら**アカウントも課金設定も追加せず**に自動デプロイまで済みます。

Firebase を選ぶ意味が出てくるのは、**APIキーをサーバー側に隠したくなったとき**です。
今の作りだとスマホでもキーを1度手入力する必要があり、キーは端末のブラウザに保存されます。
これが煩わしい・避けたい場合は、キーを持った中継サーバー（Firebase Functions や Cloudflare Workers）を挟む形になります。
そのときは声をかけてください。

## 制限

- モーラ数は漢字の読みを推測しません（AI が書いた行を除く）
- メロディは1小節の分割（4分／8分／16分）の上に置きます。3連符や細かいタイは表現できません
- メロディはキーのスケール上の音だけを扱います（半音の経過音は置けません）
- 再生音は確認用の簡易なもので、書き出し（MIDI / WAV）には対応していません
- オフラインでは動きません（Service Worker は入れていません）
